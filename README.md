# 💈 गाँव की सैलून (Gaon Ki Saloon)

![Gaon Ki Saloon Banner](./salon_bg.webp)

> **"गाँव की सैलून"** is an atmospheric, nostalgic landing page web application that captures the timeless essence of a traditional Indian village barbershop. Built with modern web technologies, it features rich visual aesthetics, real-time clock, glassmorphism UI controls, and live background audio playback powered by YouTube Music playlists.

---

## ✨ Features

- 🎨 **Cinematic Nostalgic Aesthetics**: High-resolution authentic Indian barbershop background imagery with film noise texture and ambient gradient overlays.
- 🎵 **Live YouTube Playlist Integration**: Seamless streaming playback synced with YouTube Music playlists via YouTube IFrame API.
- 🎛️ **Glassmorphism Music Controller**: Full audio controls including Play, Pause, Next Track, Previous Track, Volume Mute, and Interactive Seekbar.
- 🕒 **Live IST Clock & Status Badge**: Dynamic real-time clock and live saloon status indicator.
- 📱 **Fully Responsive Design**: Optimized across mobile, tablet, and desktop viewports.
- 🔍 **SEO & Search Engine Optimized**: Meta tags, OpenGraph, Twitter Cards, and Schema.org JSON-LD structured data for fast indexing.

---

## 🛠️ Tech Stack

- **Frontend Framework**: [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)

## 🚀 Getting Started

Follow these steps to set up and run the project locally on your machine.

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v16 or higher) installed.

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Shivamg0520/gaon_ki_salon.git
   cd gaon_ki_salon
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173`.

4. **Build for Production**:
   ```bash
   npm run build
   ```
   The production ready files will be generated in the `dist/` directory.
